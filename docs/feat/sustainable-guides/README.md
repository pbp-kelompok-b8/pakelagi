## AI & Development Disclosure (`sustainableguides`)

### 1. Peran & Bantuan AI (Google Gemini)
Pengembangan modul `sustainableguides` memanfaatkan kolaborasi dengan asisten AI (Google Gemini) sebagai *thought partner* dan referensi arsitektur pada area berikut:
* **Arsitektur Keamanan & Mitigasi XSS Berlapis:** Perumusan strategi sanitasi input di sisi server pada `GuideForm` (`clean_title`, `clean_ringkasan`, `clean_konten`, dan `clean_image_url`) menggunakan `strip_tags()`, serta pengamanan *output* Markdown pada `guide_detail` menggunakan `escape()` sebelum konversi `md.convert()` dan pemblokiran skema tautan `javascript:`.
* **Pola Integrasi AJAX HTMX:** Penyusunan atribut pertukaran DOM parsial (`hx-get`, `hx-post`, `hx-target`, `hx-select`, dan `hx-swap="outerHTML"`) untuk fitur filter kategori di katalog jurnal serta pengiriman dan penghapusan draf tanpa *full page reload*[cite: 1].
* **Logika Views & Validasi State:** Perancangan alur pengembalian *instance* `form` yang gagal divalidasi dari `submit_draft` ke `user_drafts`, pembatasan hak *edit/delete* khusus untuk draf berstatus `PENDING`, serta pencegahan kebocoran artikel terjadwal menggunakan filter `date_published__lte=timezone.now()`.
* **Skenario Unit Testing:** Penyusunan struktur pengujian otomatis pada `sustainableguides/tests.py` yang mencakup pengujian validasi form dan ketahanan XSS (`GuideFormAndSecurityTests`), visibilitas halaman publik (`GuidePublicViewsTests`), serta otorisasi kepemilikan CRUD member (`GuideMemberCRUDAndAuthTests`).

### 2. Implementasi Manual, Pengetikan Ulang, & Kustomisasi Mandiri
Seluruh kode pada modul `sustainableguides` tidak sekadar disalin tempel (*copy-paste*), melainkan diketik ulang, diadaptasi, dan di-*debug* secara manual agar menyatu dengan ekosistem proyek **Pakelagi**:
* **Perancangan Model & Properti Kalkulasi (`models.py`):** Penyesuaian skema tabel `sustainable_guide`, penambahan relasi `approved_by` (`on_delete=models.SET_NULL`), serta penulisan fungsi `@property` untuk kalkulasi otomatis estimasi waktu baca (`reading_time`), penentuan nama penulis (`author_name` dengan *fallback* `"Tim Pakelagi"` untuk *superuser*), dan nama moderator (`moderator_name`).
* **Translasi Desain Figma ke Tailwind CSS:** Penyusunan tata letak responsif (*Mobile-First Flexbox & Grid*), penyesuaian *spacing*, warna, dan penerapan tipografi editorial (`Cormorant Garamond` dan `Jost`) pada `guide_list.html`, `guide_detail.html`, `user_drafts.html`, serta `edit_draft.html`[cite: 1].
* **Styling Kustom Markdown & Indikator HTMX:** Penulisan aturan CSS spesifik untuk merapikan elemen hasil konversi Markdown (`.markdown-body` untuk tipografi subjudul, tabel, *list*, dan *blockquote* beraksen *amber*) serta *sidebar* daftar isi (`.toc-wrapper`) di `guide_detail.html`[cite: 1]. Penambahan CSS `.htmx-request.htmx-submit-btn` juga diimplementasikan pada `user_drafts.html` untuk menampilkan status visual `"Mengirim..."` dan mencegah klik ganda saat pengiriman draf[cite: 1].
* **Modularisasi Komponen Template (Prinsip DRY):** Pemisahan elemen kartu artikel ke dalam `templates/sustainableguides/components/guide_card.html` dan lencana status ke dalam `templates/sustainableguides/components/status_badge.html` menggunakan tag `{% include %}` agar dapat digunakan kembali secara konsisten di berbagai halaman[cite: 1].
* **Debugging Routing & Integrasi Antar-Modul:** Pelacakan dan perbaikan *error* `NoReverseMatch` secara mandiri pada navigasi *breadcrumbs* dan tombol aksi di `edit_draft.html` untuk menyelaraskan pemanggilan rute ke `sustainableguides:my_submissions`, serta pengaitan tautan profil publik (`profiles:profile_public`) dan autentikasi (`accounts:logout`) di dalam template[cite: 1].
